## Proposal Summary

Correct the v0.1 architecture decision to accurately reflect the runtime roles in the Wolfpack system. The v0.1 canon incorrectly elevated OpenClaw/ClawBro to a primary control plane role. The corrected architecture should:

1. **Demote OpenClaw/ClawBro** from primary control plane to replaceable execution worker
2. **Elevate ChatGPT/Eterna** as the cognitive orchestration layer
3. **Elevate GitHub** as institutional memory and task bus
4. **Prefer deterministic workflows / GitHub Actions / n8n** as the orchestration layer
5. **Preserve OpenClaw only as optional sandbox/execution infrastructure**

---

## Motivation

The v0.1 canon incorrectly positioned OpenClaw as the "primary control plane" and "central OS" of the Wolfpack system. In practice:

- OpenClaw is a replaceable execution worker (can be swapped for another agent runtime)
- The AI orchestration layer (ChatGPT/Eterna) owns cognitive decisions
- GitHub owns institutional memory, task bus, and canonical state
- Deterministic workflows own orchestration scheduling
- OpenClaw owns only sandboxed execution when preferred

This correction ensures the canon accurately reflects the actual architecture and guides future decisions correctly.
